Account Deletion

App Name: Policy Alpha

Developer: GeneralSoft

1. Do I need an account?

Policy Alpha does not require users to create an account to use the app. We do not maintain user profiles or persistent user accounts.

2. What data is associated with my usage?

The app does not store personal data, audio recordings, voice data, or speech transcripts. Any audio used for speech-to-text functionality is processed temporarily in memory and is discarded immediately after use.

3. How to request data or account deletion

If you would still like to request confirmation of data deletion or have questions regarding data handling, you may contact us using the method below:

Email: support@generalsoft.com

Please include the subject line:

"Account Deletion Request – Policy Alpha"

4. Deletion timeline

Since no persistent user data is stored, there is no data retained after app usage. Any confirmation requests will be handled within 7 business days.

5. What data is not retained

  • Audio recordings
  • Speech transcripts
  • User profiles or identifiers
  • Device identifiers
  • Usage history
